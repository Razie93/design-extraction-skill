# Design Extraction

Turn a photographed/mockup design into reusable flat artwork, not just a style description. This is a portable Agent Skill for any assistant with image inspection and file-creation capabilities; use the host agent's available tools rather than assuming a particular product. Match visible design closely and distinguish recovered pixels from reconstruction. A photo alone cannot restore hidden artwork or detail lost to blur, compression, folds, glare, or low resolution.

## When to Use

- A user supplies a mockup, sign, product photo, souvenir, shirt, mug, package, poster, or screen and wants its design isolated, recreated, or adapted.
- They need a separate editable SVG for Adobe Illustrator alongside the extracted PNG, or an accurate design specification.
- Do not use for a new design with no reference or a generic visual critique.

## Inputs and Default Deliverables

- **Required user crop:** The user must crop the image to the exact subject/design they want extracted before submitting it. The crop should include the whole design with a small margin, without cutting off letters or edges. If the provided image is uncropped, contains multiple possible subjects, or crops off essential artwork, ask the user for a corrected crop and wait; do not choose or crop the target for them. The uncropped original may be supplied as extra context, but it does not replace the required crop.
- Inspect the actual source visually (render PDF pages as images if needed). If there is an original layered/vector file, prefer extracting its layers over tracing a photo. For a link, retrieve the highest-quality lawful source available; do not infer details from a thumbnail. If the current agent cannot inspect the image or create files, state that limitation instead of claiming an extraction was completed.
- Confirm that the user's crop identifies the intended design and whether they want exact reproduction, a cleaned reconstruction, or an adaptation. Ask only when the choice changes the artwork or critical text is unreadable. Do not silently redesign.
- Unless specified otherwise, preserve wording, colors, proportions, composition, and orientation. Deliver two separate artwork files by default: `artwork_transparent.png` (or an honestly named opaque PNG if isolation is impossible) and `artwork_editable.svg` for Adobe Illustrator. The SVG must be meaningfully editable, not a bitmap wrapped in an SVG; if faithful vector reconstruction is impossible, state what is not editable rather than inventing details. Do not generate separate documentation or preview files.
- Work in a dedicated output folder, leaving the source untouched. Record source dimensions and reference images; do not place copyrighted source photos in a public repo without authorization.

## Procedure

1. **Validate the user crop and inventory before drawing.** Confirm it shows one unambiguous target with all visible edges intact; if not, request a new crop before proceeding. Identify the design boundary within that crop; separate artwork from substrate, frame, garment seams, reflections, environment, and photographic shadows. Transcribe every visible character verbatim, including case, punctuation, line breaks, and direction. Note shapes, strokes, logos, colors, texture, gradients, negative space, layer order, alignment, and approximate relative dimensions. Label hidden/unreadable content rather than guessing it.
2. **Classify recovery.** Mark each element as DIRECT (original digital layer or recoverable pixels), RECTIFIED (flat photographed plane), RECONSTRUCTED (redrawn from evidence), or UNKNOWN (insufficient evidence). For planar surfaces, identify four real artwork-plane corners or reliable parallel guides and record them. A single homography cannot flatten a mug or cloth fold: use original art or adequate multiple views for a supported reconstruction; otherwise deliver only the visible portion and state that faithful flat art is unavailable. If exact fidelity matters, ask for a straight-on image, alternate angles, or original art. Pass: no unknown element is silently filled in.
3. **Build non-destructively and clean noise.** Preserve the user's full-resolution crop unchanged (and the original photo if supplied), then create a separate rectified working image where warranted; record landmark positions and why the chosen output size is defensible. Correct orientation and perspective before final masking; retain native detail rather than upscaling to imply it exists. Decide explicitly whether apparent background color/texture is printed art, substrate, or inseparable. Use the available image editor or image-processing tools (for example, Pillow, OpenCV, or a vector editor) for measured crops, perspective transforms, masks, selective denoising, and exports; inspect the result visually. Remove visible camera grain, compression speckles, stray pixels, and mask-edge noise from the generated artwork using the least aggressive local cleanup that works; keep edges, small lettering, fine strokes, gradients, and intentional printed texture intact. Do not apply a blanket blur, plastic-looking smoothing, invented detail, or sharpening halos. Remove substrate and cast lighting only where separable; retain intentional artwork background, texture, and shadows. Avoid global color-keying if the same color appears within the art, and avoid generative fill for evidence-free regions. If white ink or an opaque printed panel cannot be isolated from white substrate, keep an opaque panel or label a reconstruction instead of silently making it transparent. Pass: isolated artwork is clean at its real native resolution, contains all observed design details, and has no obvious substrate or frame.
4. **Build an Illustrator-editable vector separately.** Reconstruct simple marks as native SVG paths, shapes, strokes, gradients, and named groups, with a sensible `viewBox` and distinct objects for elements a designer may move or recolor. Keep fully legible text as live SVG text where a suitable font is available, preserving spelling, weight, tracking, hierarchy, baseline, curves, and line breaks; identify the font or a disclosed substitute. Converting letters to outlines preserves shapes but removes text editability; disclose this trade-off. Complex photo/illustration content may remain a separately identifiable embedded raster element only when a faithful vector rebuild is not possible; an SVG made solely of an embedded bitmap does not meet the editable-SVG requirement. Preserve visible effects rather than imagined brand styling. Pass: native vector/text elements are separately selectable and the SVG visually matches the source without invented content.
5. **Measure and check.** Estimate layout with normalized coordinates/ratios so it can scale without pretending the photo reveals physical dimensions. Sample several less-lit/less-glared areas for approximate colors; distinguish observed values from brand/print specifications. Keep working notes on mask and artwork-background decisions, perspective landmarks, output-size rationale, exact text, font-match confidence, and unknowns for your own verification; do not export them as a report. Pass: the artwork matches all recoverable evidence, and uncertainties are identified for the handoff.
6. **Export two separate artwork files.** Keep `source_crop.png` and, if needed, `rectified_working.png` as working files, not default deliverables. Deliver `artwork_transparent.png` when genuine isolation is possible (otherwise `artwork_opaque.png` or a clearly labeled reconstruction) AND `artwork_editable.svg` containing the editable vector/text elements described above. Place separate designs in numbered subfolders. If the reference does not support a meaningfully editable SVG, explain the blocker and do not mislabel an embedded bitmap as editable. Do not export separate previews or reports. Preserve aspect ratio; do not claim upscaling restores lost detail. For print requests, obtain actual dimensions and vendor profile/bleed requirements before claiming press readiness. Pass: both promised artwork files exist, open, and are named truthfully, or the specific SVG limitation is disclosed.
7. **Run two-pass quality control.** Technical pass: verify dimensions, orientation, color mode, non-empty content, alpha where promised, and correct file formats; parse the SVG, inspect its native text/path/shape/group structure, and open it in Adobe Illustrator when available. Visual pass: render and compare BOTH PNG and SVG at thumbnail and 100%/200% temporarily over light, dark, and checkerboard backgrounds without exporting a preview; compare side by side with the source and, for flat prints, reproject onto the source photo. Check every character, logo contour, color relationship, spacing, edge halo, alpha decontamination against both light and dark backgrounds, missing stroke, stray pixel, crop margin, residual speckling/grain, and denoising damage to fine details or deliberate texture. Fix visible defects and repeat; do not label an enlarged, smoothed image high-resolution when the source cannot support it. Pass: both generated files look clean and sharp at their supported resolution, with no material discrepancy in recoverable content unreported; disclose every remaining approximation or non-editable element.

## Surface-Specific Decisions

- **Signage:** isolate printed face from frame, lighting, wall, and mounting hardware. Check exact wording and letter spacing; preserve brand marks without substituting generic icons.
- **Souvenirs and apparel:** account for cylinder wrap, cloth stretch, seams, and folds. An unseen back or folded section remains UNKNOWN, not mirrored or invented.
- **Packaging:** extract each visible panel separately; never invent unseen panels, dielines, barcodes, or safe/bleed zones.
- **Digital screens:** separate interface art from bezel, glare, and screen perspective. Prefer direct UI assets if available.

## Quality Bar and Failure Modes

- A prose description, a cropped product photo, or a transparent PNG with a photographic rectangle still attached is not an extracted design.
- High quality requires clean backgrounds and edges without visible accidental noise; retain intentional texture and do not claim that denoising or upscaling recovers source detail that was never captured.
- Editable means native selectable vector shapes, text, and groups in the separate SVG, not merely an embedded bitmap. If font or illustration accuracy cannot be established, state which elements are substituted or raster-only; never claim full editability.
- Color values from a photo are approximate under its lighting; never label them official brand colors. Do not assert ownership or official brand approval.
- Do not hide low confidence behind polished rendering. If essential text/marks cannot be read, deliver the recoverable portion and request a better reference rather than fabricating a complete design.

## Verification and Handoff

- Source remains unchanged; both PNG and SVG were opened and visually inspected. If the host cannot create or verify the actual files, do not call the extraction finished.
- Do not create a report or standalone artwork preview; communicate only necessary fidelity caveats in the final response.
- Tell the user precisely which files are faithful extractions versus reconstructions, what remains uncertain, and whether the result is suitable for screen use only or has verified print specifications. Do not claim that an untested output is high-fidelity.
